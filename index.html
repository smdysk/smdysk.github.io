Instagram to GBP autopost

Instagramに投稿された写真を、その事業者のGoogleビジネスプロフィールの「最新情報」へ自動で転載するツールです。

何をするツールか

店舗や事業者がInstagramに写真を投稿し、その本文に#GBPを付けると、本ツールがその投稿を読み取り、同じ事業者のGoogleビジネスプロフィールに投稿として登録します。#GBPの付いていない投稿と、写真以外の投稿は対象になりません。

登録した内容は、Googleビジネスプロフィールの投稿として一般に公開されます。

動作するのは、導入先の事業者が契約しているレンタルサーバーの中です。運営者がサーバーを用意して預かる形ではありません。

使う仕組み

  • Instagram Graph API — 対象アカウントの投稿（画像、本文、投稿日時）を読み取ります
  • Google Business Profile API — 読み取った投稿をGoogleビジネスプロフィールに登録します

Googleビジネスプロフィールへの登録には、そのプロフィールを管理する権限（business.manage）が必要です。この権限はプロフィール全般を管理できるものですが、本ツールでは投稿の登録にのみ使用します。権限は導入先の事業者から付与を受けたうえで使用します。

扱う情報

本ツールが取り扱うのは、導入先の事業者が自分で公開したInstagramの投稿と、その事業者のGoogleビジネスプロフィールに関する情報です。投稿の画像や本文に顧客や従業員などの情報が含まれる場合は、それらも投稿の内容として取り扱います。

本ツール自体に、閲覧者から情報を入力してもらう機能はありません。なお、この紹介ページはGitHub Pagesで公開しており、GitHubがアクセス元のIPアドレスを記録します。

詳しくはプライバシーポリシーをご覧ください。

提供の形

本ツールは、特定の1店舗からの受託業務として開発中です。導入先のレンタルサーバー上で動作する予定で、一般向けの利用登録や配布は行いません。
